# 项目任务与验收要求

## 1. 项目背景

本项目为《广义线性模型》课程期中 Project，研究医疗保险费用等级的统计解释与预测，使用 R 语言实现。任务依据为老师提供的《期中Project数据集说明及要求.docx》。

原始数据包含 1,338 条记录、9 个特征列及 9 个有序响应类别（0–8），等级越高表示医疗费用越高。地区由四个指示列重构为一个分类变量后，建模数据包含年龄、性别、BMI、子女数量、吸烟状态、地区六个解释变量及响应变量 y。

## 2. 课程任务

### 任务一：有序费用等级建模

- [ ] 核验原数据按 7:3 随机划分训练集与验证集。
- [ ] 建立 Logistic 回归模型，利用投保人特征预测或解释医疗支出等级。
- [ ] 提供参数估计、统计检验、模型评估与模型诊断。
- [ ] 提供完整 R 代码及详细结果分析。

### 任务二：最优模型选择与预测

- [ ] 给出最优候选模型的选择依据。
- [ ] 在验证集上评价所选模型。
- [ ] 输出混淆矩阵和二次加权 Cohen's Kappa（QWK）。

### 任务三：最高费用等级建模

- [ ] 将 y=8 定义为正类，其余等级定义为负类。
- [ ] 按 7:1.5:1.5 随机划分训练集、检验集与验证集。
- [ ] 建立二分类 Logistic 回归，分析最高费用等级群体特征。
- [ ] 提供参数估计、统计检验、模型评估、模型诊断、完整 R 代码及详细结果分析。

以上清单为课程要求的核验入口，实际完成状态见 `03_project_acceptance.md`。

## 3. 项目实施规范（自主增加）

课程要求之外，本项目采用训练集内部交叉验证选择有序模型，使用二分类检验集选择模型及阈值，最终验证集用于独立评价。保存随机划分索引、模型、结果表格及图形，避免使用最终验证集调参。

工程交付包括 R 脚本、统计报告、项目文档、README 和依赖记录。公开前核查数据授权、模型对象中的原始观测及报告个人信息。
